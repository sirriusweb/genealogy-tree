# 🌳 Генеалогическое древо (Genealogy Tree)

**Восстановите и сохраните историю вашей семьи.** 
Программа для создания, редактирования и визуализации генеалогического древа. Работает полностью офлайн, гарантируя абсолютную приватность ваших данных.

---

### 🔒 100% Приватность (Без облаков)
Ваши семейные тайны принадлежат только вам. Программа не отправляет данные на сторонние серверы. Вся информация, включая фото, видео и заметки, хранится локально на вашем компьютере. Интернет нужен только один раз — для активации.

### 🚀 Производительность без границ
Дерево легко масштабируется до **300+ персон** и более. Благодаря оптимизированному движку отрисовки, программа не зависает даже на огромных деревьях. Плавное перетаскивание карточек и мгновенная реакция интерфейса.

### 🧠 Умная структура поколений
Программа сама следит за правильностью связей. Она не позволит случайно поставить ребёнка выше родителей или перепутать супругов. Сетка поколений выстраивается автоматически, сохраняя аккуратный вид вашего древа.

### 🌿 Ветки и группы
- **Ветки:** Фокусируйтесь на отдельной линии (например, «Ветвь по маминой линии»), не отвлекаясь на всё дерево сразу.
- **Группы:** Выделяйте целые «кусты» родственников (например, семью двоюродного брата) и перетаскивайте их вместе, не задевая остальных.

### 📥 Импорт и экспорт (Без привязки)
- **GEDCOM (.ged):** Полная совместимость с мировыми стандартами генеалогии. Импортируйте данные из MyHeritage, «Древа Жизни» или Ancestry.
- **JSON:** Создавайте полные резервные копии базы данных.
- **SVG:** Экспортируйте дерево в высококачественную картинку для печати или отправки родственникам.

### 🖼️ Богатая медиатека
Добавляйте к каждой персоне фотографии, видеозаписи и «Интересные факты» (биография, профессия, семейные легенды). Выбирайте удачный портрет для аватара, который будет виден прямо на карточке.

### 🌐 Мультиязычность и интерфейс
- Поддержка **9 языков** (включая русский, английский, китайский, арабский и др.), с корректным отображением справа налево (RTL).
- Гибкая настройка шрифтов (размер, семейство, начертание) для каждой части карточки.
- Удобные горячие клавиши (Ctrl+Z для отмены, Shift+Клик для мультивыбора).
